# Vela (FKA SR Labs)

> Vela Trading Technologies (formerly SR Labs) was a New York-based provider of low-latency market data feed handlers, execution gateways, and trading platforms for capital markets. Vela merged into Exegy in May 2021 and no longer operates independently; its website (tradevela.com) is offline and its products (SuperFeed, Metro, DMA Platform) now live under Exegy.

Vela had no self-serve public HTTP API. Its market data feed, SuperFeed, was published through the open-source OpenMAMA API (C++, C#, Java), and it ran an OpenMAMA Developer Program. Its OptionsCity acquisition (2017) exposed the City Trader REST API, whose hosts are now decommissioned.

## Successor

- [Exegy](https://www.exegy.com/): the merged company; see the api-evangelist exegy profile for the current surface

## Legacy artifacts

- [GitHub org (tradevela)](https://github.com/tradevela): 3 public repos, largely inactive since 2017
- [city-trader-python-lib](https://github.com/tradevela/city-trader-python-lib): first-party Python client for the retired OptionsCity City Trader REST API
- [OpenMAMA](https://openmama.finos.org/): the open-source middleware API Vela's SuperFeed published through (FINOS project, not Vela-owned)
